- 조준: 화면 레이를 수평면에 투영한 조준점, 우클릭 정밀 조준(이동 감속, 탄퍼짐 감소)
- 회피: 이동 입력 방향 대쉬, 앞부분 무적 구간, 스태미나 소모. 3주차 피격자 최종 확인을 위해 무적 여부를 외부에서 읽을 수 있게 함
- 사격: 발사 정보(FireInfo)로 투사체 발사, 오브젝트 풀, 프레임 간 레이캐스트로 관통 방지, 무기별 최대 사거리
- 명중 모델: 탄퍼짐(이동, 달리기 직후, 연사 누적, 정밀 조준), 탄퍼짐에 따라 크기가 바뀌는 원형 조준점
- 탄창과 재장전: 회피·무기 교체 시 취소, 빈 탄창 자동 재장전
- 무기 데이터: WeaponData ScriptableObject, 권총·소총·산탄총 테스트 데이터
- 더미 적: 체력, 피격 깜빡임, 데미지 숫자, 재등장. 사격 화면 흔들림(Impulse)
- 캐릭터 모델과 애니메이션: Toon Shooter Game Kit(Generic, 팩 클립만 사용), Animator 하나·레이어 하나·블렌드 트리 없음, 정수 파라미터 State로 한 번에 클립 하나만 재생
- 상수 정리: Core/Define 폴더에 열거형(Enum.cs), 애니메이터 파라미터·상태, 셰이더 속성 ID를 모음
## 주요 기술 결정
- 네트워크: Fusion 2에서 PUN 2로 변경 (숙련도와 일정). 마스터 클라이언트 권한 구조
- 이동은 CharacterController, 팀원끼리 충돌 없음 (좁은 곳 길막과 원격 캐릭터 보간 덜컹거림 방지)
- 모듈 의존: Combat은 Player를 참조하지만 Player는 Combat을 모름. 전투 입력도 별도 클래스로 분리
- 애니메이션 상태는 PlayerAnimationController 한 곳에서 우선순위로 결정하고, Animator에 값을 쓰는 곳도 이 클래스 하나로 제한
- 판정은 전부 투사체 방식. 2주차 RPC 전송을 대비해 발사를 FireInfo 구조체로 표현
## 해결한 기술 문제
 
### 카메라가 플레이어를 따라갈 때 떨림
- 증상: 카메라 타깃을 별도 스크립트로 플레이어 위치에 맞추자 이동 중 화면이 미세하게 떨림
- 원인: 타깃 이동 스크립트와 플레이어 이동의 실행 순서가 프레임마다 어긋남
- 해결: 따라가는 스크립트를 없애고 카메라 타깃을 플레이어의 자식 오브젝트로 둠. 정밀 조준 오프셋만 로컬 위치로 움직임
- 배운 점: 따라가게 만드는 코드보다 계층 구조로 해결할 수 있는지 먼저 본다
### 연속 회피 시 대쉬 클립이 처음부터 재생되지 않음
- 증상: Space를 연타하면 두 번째 회피부터 대쉬 동작이 이어서 재생되지 않음
- 원인: State 값이 회피로 유지되어 Any State 전환이 다시 일어나지 않음
- 해결: 회피 시작 이벤트에서만 예외로 Animator.Play로 회피 상태를 처음부터 재생 (상태 이름 해시는 AnimatorStates에)
- 배운 점: 파라미터 방식의 한계가 있는 지점은 예외를 한 곳에 모으고 이유를 주석으로 남긴다
### 이동 중 재장전 클립이 미끄러져 보임
- 증상: 전신 재장전 클립을 이동 중에 재생하면 발이 미끄러짐
- 원인: 상체 레이어 없이 클립 하나만 재생하는 구조
- 해결: 재장전 클립은 멈춰 있을 때만 재생하고, 이동 중에는 이동 클립을 유지. 재장전 시간 동안 클립 반복
